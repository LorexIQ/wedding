# Конверт-приветствие и салют — дизайн

Дата: 2026-07-31

Дополняет [2026-07-31-invitation-system-design.md](2026-07-31-invitation-system-design.md) (спека B).
Оттуда используются: столбец `envelope_opened` в `guests`, `POST /api/invite/[code]/open`
(эндпоинт `markEnvelopeOpened` — уже реализован и покрыт тестами), чекбокс «Открыл конверт» в
админке (`toggleEnvelopeOpened`), `useState('inviteGuest')` из глобальной мидлвари.

Это саб-проект C из трёх, на которые был разбит исходный бриф 2026-07-30 (см. память
`pending_subprojects_a_c.md`). Саб-проект A (защита телефона) — отдельная спека, не пересекается.

## Цель

Первый визит гостя на `/` (после перехода по пригласительной ссылке) встречает не сразу сайт, а
экран-конверт: гость должен нажать, чтобы «распечатать» приглашение. После открытия — сайт
показывается, синхронно запускается салют. Факт открытия — постоянный флаг на госте
(`envelope_opened`), не сессионный: админ может сбросить его, чтобы конверт показался снова.

Конфетти (`TheConfetti.vue`) уже реализовано и сейчас стреляет безусловно на каждой загрузке
страницы. Эта спека переводит её на управление извне (метод `fire()`) и решает, кто и когда её
запускает: либо сразу при заходе (конверт уже был открыт раньше), либо по завершении анимации
открытия конверта.

## Компоненты и поток данных

Три компонента, каждый отвечает за одно:

- **`TheEnvelope.vue`** (новый) — рендерится только если `inviteGuest.value?.envelopeOpened ===
  false` (`v-if`, без гостя/при `true` — не рендерится вовсе). Полноэкранный fixed-оверлей поверх
  уже отрисованного сайта (сайт в DOM сразу — OG/SEO не страдают, крауler видит head независимо от
  того, что визуально сверху). Пока висит — блокирует скролл `body` (`overflow:hidden`), чтобы
  контент под конвертом не подглядывался краем при свайпе/ресайзе. Владеет анимацией открытия и
  эмитит `opened`, когда сдвиг долистал до конца. Ничего не знает про конфетти и не шлёт сетевых
  запросов сама.
- **`TheConfetti.vue`** (правится) — теряет автозапуск на `mount`. Готовит canvas/resize как
  сейчас, но залп не стартует, пока её не попросят: `defineExpose({ fire })`.
- **`index.vue`** (правится) — координатор. Держит `ref` на `TheConfetti`:
  - на `mount`, если `inviteGuest.value?.envelopeOpened === true` → сразу `confettiRef.fire()`
    (старое поведение «стреляет на каждой загрузке» сохраняется для гостей, кто уже открывал
    конверт раньше).
  - слушает `@opened` от `TheEnvelope` → `confettiRef.fire()` **и параллельно**, не дожидаясь
    друг друга: `$fetch('/api/invite/[code]/open', { method: 'POST' }).catch(console.error)`.
    Код гостя берётся из `useInviteCode()` (уже используется в `invite/[code].vue`). Неудача
    запроса не блокирует ничего визуально — гость не должен видеть ошибку из-за фонового
    сетевого сбоя; на следующей загрузке конверт просто покажется снова (флаг на сервере не
    выставился), это приемлемый фолбэк.

## Визуал конверта

Крафт-конверт в палитре сайта (`--linen`/`--paper`/`--rule`/`--wheat`/`--sage`, шрифт `--serif`).
По центру — печать: шалфейная (`--sage`) звезда `✦`, без монограммы. Над печатью — нейтральная
надпись без имени гостя, например «Откройте письмо» (курсив, `--ink-soft`) — точную формулировку
можно поправить по месту при вёрстке, без ФИО.

Через 5с бездействия (если гость ещё не кликнул) — на печати запускается тихая зацикленная
пульс-точка (`scale` + `opacity`, `~1.6s` период), гаснет по клику. Таймер стартует при монтировании
компонента и снимается при клике/размонтировании.

Размеры — не фиксированные px, а адаптивные (`clamp`/`vw`, по аналогии с `--band`/`--measure` в
`main.css`), центрирование по вертикали и горизонтали на весь вьюпорт.

## Анимация открытия

Клик по всей карточке конверта (не только по печати — так проще попасть на мобильном), только пока
`opening === false` (флаг блокирует повторные клики):

1. `opening = true`, hint-таймер и пульс останавливаются.
2. **Флап-переворот**: треугольная верхняя часть открывается 3D-переворотом, как страница
   книги — `perspective` на контейнере, `transform-origin` на линии сгиба (низ треугольника),
   `rotateX` от `0` до примерно `-160deg`, `~0.6s`.
3. **Пауза** `0.5s` (`setTimeout`).
4. **Сдвиг**: весь оверлей (конверт + подложка) уезжает вниз за пределы экрана, `~0.6–0.8s`,
   снизу открывается уже отрисованный сайт.
5. По завершении сдвига — `emit('opened')`, компонент убирается (`v-if` по локальному `closed`).

### `prefers-reduced-motion`

Шаги 2–4 схлопываются в один кадр: по клику `closed = true` немедленно (флап не показывается
открытым ни на миг, никакой промежуточной анимации), `emit('opened')` сразу же. `TheConfetti.fire()`
всё равно не даёт визуального эффекта — компонент уже сейчас сам себя глушит на этом медиа-запросе,
менять эту часть не нужно.

## Конфетти — вынос констант

Новый файл `app/utils/confettiConfig.ts` (по аналогии с `phone.ts`/`formatFio.ts`): `COLORS`,
`GRAVITY`, `DRAG`, число искр/лент в `burst()`, тайминг `salvo`. `TheConfetti.vue` импортирует
оттуда, логика самой анимации не меняется — только цифры переезжают.

## Бэкенд

Без изменений — `POST /api/invite/[code]/open` (`markEnvelopeOpened`) уже реализован в спеке B и
покрыт тестом (`tests/server/api/invite.test.ts`). Эта спека только начинает его использовать с
фронта.

## Тестирование

- Автотесты не требуются новые: серверная часть уже покрыта; клиентская — чистая CSS/JS-анимация
  без бизнес-логики, тестировать нечем содержательным (по аналогии с текущим отсутствием тестов у
  `TheConfetti.vue`).
- Ручной прогон: свежий инвайт → конверт виден → 5с ждём → пульс появляется → клик → флап-переворот
  → пауза → сдвиг → конфетти + `envelopeOpened=true` в БД (проверить в админке) → рефреш страницы у
  гостя → конверта больше нет, конфетти стреляет сразу на mount. Админ снимает галку «Открыл
  конверт» → рефреш у гостя → конверт снова показывается. `prefers-reduced-motion` (эмуляция в
  DevTools) → конверт исчезает одним кадром без промежуточных состояний, конфетти не запускается.

## Вне рамок

- Персонализация надписи именем гостя — сознательно не делаем (см. решение выше).
- Иная механика открытия (свайп, долгий тап) — только клик/тап по всей карточке.
- Массовый сброс `envelope_opened` для всех гостей разом — только по одному через существующий
  чекбокс в админке.
